用词big wrong→big problem
wrong 在这里不是可数名词；说“很大的问题”用 big problem。
语法for expression→with expressing myself
介词搭配与反身代词，表达“表达自己”要用 express myself。

very 不能直接修饰动词；英文用 really like。

Design intent

  • HUD 贴着光标上方 6px，像输入法候选条；结果卡在下方，视线不离开句子。
  • 暖黑背景 + 香槟金，避免“AI 工具”的冷蓝紫。
  • 问题行严格三层：类型标签 / 原文 → 修改 / 中文理由。
  • 主按钮只有「检查 / 翻译 / 解释」，其余收进 ⋯。
  • 卡片 380px，足够放下两行原文与三条问题。

Material

  • HUD 与卡片使用 24–30px backdrop blur，边缘 1px 高光。
  • 阴影分两层：环境阴影 + 内侧 1px 高光。
  • 金色只用于 active 与主操作，不铺满。
