PARENO · HUD icon study · 2026-11-14

把三个图标换成中性符号

同一枚 HUD，四种图标方案。目标是：图标不抢字、不表达情绪，只做“可以点”的提示；不改变三键的文字与顺序（检查 / 翻译 / 解释）。

A · 当前语义图标
现状。语义太明确：勾、翻译、问号各自在讲故事，视觉上也偏“工具集合”。
B · 纯文字无图标
最中性。文字本身已经足够清楚，按钮更安静；缺点是少了“可点”的视觉锚点，需要靠胶囊背景与 hover 补足。
C · 极简线条无外圈
保留“点得动”的暗示，但去掉图标外圈。中性、克制，与 15px 字号最协调；推荐作为折中方案。
D · 几何符号抽象标记
最抽象：竖线 / 圆 / 菱形。完全不表意，但容易变成装饰噪音，用户第一次用会不知道符号含义。
建议
选 C · 极简线条：去掉外圈、保留最小可读的勾 / 双向箭头 / i。既有“可点”的视觉提示，又不讲故事。若想更安静，选 B · 纯文字。
说明
这四种方案只改图标，不改三键的文案、顺序、宽度（272×38）与金色 active 状态。
图标的 stroke 统一 1.4px；尺寸 15×15；与文字间距 6px。
