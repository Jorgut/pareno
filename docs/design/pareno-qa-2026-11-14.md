## P0 · 必须先解决

1. **辅助功能权限未生效**（日志 `trusted=false`）。没有它，HUD 不显示、选区读不到。需要在系统设置中给 `Pareno Desktop.app` 打开开关，并避免再次重编译（ad-hoc 签名会重置权限）。
2. **HUD 缺第三键「解释」**，且解释模式未实现。设计已批准：检查 / 翻译 / 解释。
3. **9 个提交未推送**。GitHub 上的 main 仍是 0.7.0 时期的 `7b90d49`，CI 也没跑到迁移与设计提交。
4. **Obsidian 主分支与 Release 不一致**：main 已包含紧凑侧栏、结果操作条、整篇翻译，但 manifest 仍是 0.7.0，官网 changelog 也没有这些内容。BRAT 用户拿不到。

## P1 · 影响体验

5. **主题**：代码没有跟随系统/主题切换；设计已确认默认跟随系统，设置页后续加主题选择。
6. **视觉落地**：HUD 272×38、三键、图标 A、金色 active、毛玻璃层级都还没进代码；当前面板更接近开发版。
7. **网页输入框兜底**：AX 读不到时没有剪贴板复制方案；DSH / Chromium 类输入框可能显示“没有找到可检查的文字”。
8. **Desktop 质量门禁**：没有 Swift 测试、没有 CI、没有版本号策略。
9. **文案/环境变量**：README 的“two actions”、`WRITECHECK_OLLAMA` 需要统一为 Pareno Desktop / `PARENO_DESKTOP_OLLAMA`。
