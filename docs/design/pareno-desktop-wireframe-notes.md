# PARENO 双端线框图说明

日期：2026-11-14。本轮只做结构与交互线框，不进入桌面端代码。

## 1. 产品定位

- 一个项目、一个品牌：**PARENO**；桌面端标注为 **Pareno Desktop**。
- 两个端口：
  - `PARENO · Obsidian`：现有 Obsidian 插件。
  - `Pareno Desktop`：可下载的桌面写作工具，像输入法候选条一样贴着光标。
- 两端共享同一套结果语言：检查 / 翻译、最小修改 / 自然表达、替换 / 复制。

## 2. 线框图包含

文件：`pareno-wireframes.html`（可改），`pareno-wireframes.png`（预览）。

1. **桌面端 · 检查**：光标上方的小工具（检查 / 翻译），下方 380px 结果卡。
2. **桌面端 · 翻译**：同一张卡，切换忠实 / 自然译文，替换 / 插入下方 / 复制。
3. **Obsidian 插件**：保留完整任务（检查与润色、翻译、核对中英、解释表达、作者风格），结果行与两端一致。
4. **状态**：吸附、检查中、固定位置、无权限 / 无文本。

## 3. 共享组件

| 组件 | 规格 | 说明 |
| --- | --- | --- |
| HUD pill | 266 × 34，r18 | 检查 / 翻译 / 解释三个按钮，左侧拖动握把 |
| Result card | 380 × auto，r16 | 贴光标下方展开 |
| Source quote | 9px padding | 显示原文，最多三行 |
| Issue row | 标签 + 原文 → 修改 + 中文理由 | 两端同一结构 |
| Variant tabs | 最小修改 / 自然表达；翻译为忠实 / 自然 | 默认自然 |
| Result actions | 替换 / 复制 / ⋯ | 插件端另有重新审校 / 设置 / 清除 |

## 4. 桌面端行为

- 默认吸附光标：光标上方 6px，左对齐；空间不足时翻到下方。
- 不抢焦点；点击 HUD 不打断输入。
- 固定模式：拖动左侧握把，记住位置；菜单可切换。
- 语音输入（豆包等）完成后，文字进入输入框，HUD 跟随新光标。
- 无权限 / 无文本时不静默消失，显示原因与「打开辅助功能设置」。
