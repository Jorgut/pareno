# Pareno Desktop · 市场、商业化与 QA 回顾

日期：2026-11-15。对象：当前本地构建（Developer ID 签名，未公证），Obsidian 插件 0.8.0 作为同源产品参考。

## 一句话结论

Pareno 已经是一个**能用、有明确差异点**的 macOS 写作工具，但还不是可发布商品：分发未过 Gatekeeper、默认模型太慢、核心质量未做真实语料验收、箭头/材质等 UI 细节仍在返工。现在最该补的不是 UI，而是**分发 + 模型体验 + 真实语料 QA**。

## 1. 市场同类产品

| 产品 | 形态 | 能力 | 价格 | 与 Pareno 的关系 |
| --- | --- | --- | --- | --- |
| **Grammarly** | 系统级键盘/浏览器扩展 + 桌面 | 语法、改写、语气、团队 | Pro $12/月（年付），$30 月付 | 通用写作巨头；Pareno 不在同一量级，不能拼通用语法 |
| **Apple Writing Tools** | macOS 系统内置 | Proofread / Rewrite / Summarize / Translate | 免费 | 最大威胁：系统级、免费、无安装 |
| **LanguageTool** | 桌面 + 浏览器 + Office | 30+ 语言语法 | Premium €4.90/月（年付），€19.90 月付 | 多语言语法强；Pareno 多了「解释」和光标 HUD |
| **WunderType** | macOS 菜单栏 | 选中文本 → 快捷键 → 改写/翻译，支持 Ollama/OpenAI 兼容 | **$8.99 一次性** | 最直接竞品：同样的「任意 App 选中文本」 |
| **Poli** | macOS 菜单栏，开源 MIT | 本地 Apple Foundation Models，校对/改写/翻译/自定义提示 | **免费** | 最直接的开源竞品；本地、免费、隐私 |
| **InDraft** | macOS 菜单栏 | 选中文本 → 单快捷键原地改写/翻译 | 早期版本，GitHub | 同类交互 |
| **Sapling / Wordtune / DeepL Write** | 浏览器/桌面 | 改写、翻译、语气 | 订阅/免费额度 | 通用替代，不是光标 HUD |
| **Harper** | 开源语法引擎 | 本地语法检查 | 免费/开源 | 可作为本地检查组件，不是完整产品 |

### Pareno 的真实差异点

1. **光标旁 HUD**：不是只处理“选中文本”，而是输入时贴在光标/选区旁，三个动作直接出现。
2. **检查 / 翻译 / 解释三合一**：尤其“解释为什么错”，比单纯改写更适合语言学习者。
3. **中 / 英 / 俄三语 UI**，且翻译目标跟随界面语言。
4. **Bring your own model**：本地 Ollama、Ollama Cloud、Claude/Codex/Cursor/OpenCode CLI。
5. **Obsidian 同源**：如果插件和桌面端共享定位，可形成“写作 + 阅读 + 桌面”的组合。

### 结论

通用语法/改写已经被 Apple 免费能力和 Grammarly 占据；Pareno 不能做“又一个 Grammarly”。可守的细分是：

> **中/英/俄双语写作者 + 需要解释而不只是改写 + 希望本地/自带模型 + Obsidian 用户。**

## 2. “Beespear” 案例

按 **Beespear** 检索不到与写作工具/商业案例相关的平台或产品；搜索结果主要是拼写相近的 **BeeSpeaker**（AI 语言学习，€2M seed、6 万付费用户、2025 年预计 €5M 收入）。BeeSpeaker 属于语言学习，不是写作助手，不能直接作为同类商业案例。

如果你说的是另一个 **Beespear** 平台，请给链接或截图；目前我不能编造它的案例。

可参考的相近商业信号：

- WunderType：macOS 菜单栏写作工具，**$8.99 一次性**，说明“小工具买断”有人愿意付费。
- Poli：同类能力但**免费开源**，说明纯本地通用功能很难收费。
- Grammarly / LanguageTool：订阅制成立，但靠规模、语料、品牌和团队。

## 3. 要不要商业化

### 不建议“完全免费”作为默认

- 免费会吸引大量支持、兼容、隐私咨询；
- 公证、签名、更新、服务器都要成本；
- 通用能力有 Apple/Poli 免费替代，免费也未必换来增长。

### 也不建议直接做订阅

- 你目前没有云端推理资产，订阅需要持续成本/服务；
- 用户对“写作小工具”的订阅疲劳明显；
- 直接对标 Grammarly $12/月没有胜算。

### 推荐：Freemium + 买断 Pro

**免费版（本地）**

- 本地 Ollama 检查/翻译/解释
- 三语 UI
- 光标 HUD
- 基础结果卡

**Pro（一次性 $19–$29，或 $3–$5/月）**

- Ollama Cloud / 自带 Agent 的便捷切换
- 历史记录、收藏、术语表、自定义提示
- 多设备同步（后续）
- 团队/术语库（更后期）

**原则**：免费版必须能独立完成一次完整价值闭环；Pro 卖“便利、记忆、协作”，不卖“能不能用”。

### 先验证，不要先定价

1. 10 个目标用户访谈（中/英/俄写作、Obsidian、翻译需求）。
2. Landing page + 预约/预购，测点击与留资。
3. 手动 concierge 服务 5 个用户，观察是否愿意付 $19。
4. 有 3 个真实付费意向再投入公证、DMG、自动更新。

## 4. 当前版本 QA

### 通过

- `swift build` 通过
- `--selftest`：解码、解释字段、非法 JSON 全部通过
- Obsidian 插件 56/56 测试通过
- Developer ID 签名稳定，重编译后 TCC 仍为 `trusted=true`
- 三语 UI、检查/翻译/解释、结果卡缩放、HUD 避让输入法、空文本关闭均已实现

### P0 · 发布阻断

1. **未公证**：`spctl` 返回 `rejected: Unnotarized Developer ID`。别的 Mac 下载后会被 Gatekeeper 拦截。需要 notarization + staple + DMG。
2. **默认模型不可用/太慢**：本机只有 `gpt-oss:20b`（13GB），一次 60–100 秒；`qwen3.5:4b` 尚未安装。首次体验会像卡死。
3. **没有真实语料验收**：目前只有 selftest，没有 20–50 条中/英/俄真实文本的准确率、JSON 合法率、耗时基线。
4. **Agent 不可用**：Claude 模型权限 404、Codex 额度限制、Cursor 未登录、OpenCode server error；当前只能本地 Ollama。

### P1 · 体验/质量

5. **无取消/超时 UI**：Ollama 请求 150 秒超时，界面只有“正在…”，用户无法取消。
6. **无流式输出**：长文本等待感强。
7. **箭头为关闭状态**：当前卡片无连接指示；需要按稿子单独重做，不能继续叠补丁。
8. **无 onboarding**：首次启动没有“权限 → 模型 → 试一段”的引导。
9. **无隐私说明/数据路径展示**：本地/云端/Agent 三种去向没有明确 UI。
10. **无桌面端自动化测试/UI 测试**：只有 CLI selftest。
11. **翻译目标固定跟随 UI 语言**：没有显式“译成中文/英文/俄文”选择。
12. **无应用图标/关于页/更新机制**。

### P2 · 商业化前

13. 无历史记录、术语表、自定义提示。
14. 无崩溃上报/匿名使用统计（需隐私合规）。
15. 无 App Store 版本；Developer ID 直接分发需要 Sparkle 更新。
16. 无官网/定价页/退款政策。

## 5. 先补什么

**不要先做 UI 精修。** 顺序建议：

1. **分发**：公证 + DMG + 首次启动引导（权限/模型/试一段）。
2. **模型基线**：安装 qwen3.5:4b，默认使用；加取消、超时、耗时显示。
3. **真实语料 QA**：30 条中/英/俄文本 × 检查/翻译/解释，记录准确率、JSON 失败率、P50/P95 耗时。
4. **箭头**：按已确认的 35×15 稿，用独立 Shape 重做，先截图确认再接入。
5. **商业化验证**：Landing page + 10 次访谈 + 预购，再决定定价。
6. **测试/隐私**：桌面单测、UI smoke、隐私说明、崩溃收集。
